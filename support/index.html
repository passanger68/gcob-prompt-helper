Report a problem

Use the project’s GitHub issue tracker for reproducible behavior, documentation corrections or policy questions.

Open a GitHub issue ↗Browse existing issues ↗

What to include

  • A minimal, anonymized prompt that reproduces the issue.
  • The expected behavior and the behavior you observed.
  • Your ChatGPT client and whether the issue affects text choices or interactive controls.

GitHub issues are public. Exclude passwords, API keys, private documents and personal conversation details.
