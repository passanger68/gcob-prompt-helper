plugin.zip

  1. Download plugin.zip.

    When the verified release is available, download plugin.zip from this website and keep the ZIP file intact.

  2. Open the ZIP import screen.

    In ChatGPT on the web, open Admin console, select your workspace, and go to Plugins → Add → Upload plugin.

  3. Upload the package.

    Choose your downloaded plugin.zip and complete the upload. If validation reports a problem, keep the message and contact the publisher through Support.

  4. Install the imported plugin.

    Open GCOB Prompt Helper in your workspace’s Plugins directory and choose Install plugin or the plus (+) control if shown. If it is already installed, continue.

  5. Start using it.

    Start a new conversation, type @, select GCOB Prompt Helper under Plugins, and paste the prompt you want to improve. After clarification, choose Output the prompt or Run the prompt.

Who can import a ZIP? ZIP upload requires the upload option and appropriate permissions. In managed workspaces, an eligible owner or administrator may need to import it for you. Downloading a ZIP does not change ChatGPT permissions.

GCOB Prompt Helper is skill-only: no separate service connection, API key or GitHub account is needed.
